📖 POLYLINE EDITOR - Guide

🎨 Shapes

Click to draw at current position, Drag to canvas to place

  • Rectangle - 4-sided shape with right angles
  • Diamond - 4-sided rotated square shape
  • Ellipse - Oval shape with customizable width/height
  • Circle - Perfect round shape
  • Arrow - Directional pointer shape
  • Freehand Pencil - Draw custom polylines freely

🎯 Modes

  • Idle (ESC) - Default mode, no drawing or editing
  • Draw (B) - Click canvas to add points, create shapes
  • Move (M) - Click & drag shapes to move them around
  • Delete (D) - Click to delete, or drag area to select & delete multiple

👆 Press, Hold, Release

  • Press and hold a shape - Shows a temporary preview of the shape's previous state
  • Keep holding - The previous saved state stays visible while the mouse is held down
  • Release - The shape returns to its current state immediately
  • Hold, then drag in Move mode - The preview hides and normal moving begins

⌨️ Keyboard Shortcuts

  • B - Switch to Draw mode
  • M - Switch to Move mode
  • D - Switch to Delete mode
  • ESC - Return to Idle mode
  • Ctrl+Z - Undo last action
  • Ctrl+Y - Redo action
  • Ctrl+C - Copy selected shape
  • Ctrl+V - Paste copied shape
  • Ctrl+X - Cut selected shape
  • Ctrl+D - Duplicate selected shape
  • Del - Delete selected shape
  • Arrow Keys - Nudge selected shape
  • Scroll - Zoom in/out

🎨 Style Controls

  • Stroke Color - Choose color for shape outlines (click color buttons)
  • Size - Adjust shape dimensions (20-300px)
  • Line Width - Adjust stroke thickness (1-12px)

💾 Save & Load

  • Ctrl+S - Save drawing to browser storage
  • Auto-Save - Drawing automatically saves every action

🌓 Theme

Click the ☀ icon in top-right to switch between Light and Dark themes

📍 Selection Bar

When a shape is selected, use these buttons:

  • COPY - Copy the selected shape
  • DUP - Duplicate the selected shape
  • DEL - Delete the selected shape
