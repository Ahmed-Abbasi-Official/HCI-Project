Polyline Editor — Help Guide

✦

Drawing

Press B or click Draw mode. Click canvas to place points. Dotted preview line follows cursor. Press ESC to finish.

✥

Move Mode

Press M. Click a shape or point and drag. Press+hold to see previous state preview. Arrow keys nudge selected shape.

✕

Delete Mode

Press D. Click a point to remove it. Click a line segment to delete entire shape.

⬡

Shapes

Click sidebar shape to add at center. Drag shape onto canvas to place at exact position. Size slider controls dimensions.

▶

Shape Replay

Select a shape → click ▶ Replay in the selection bar. Watch that shape redraw step by step. Other shapes stay visible.

⊞

Snap & Grid

Press G to toggle grid snap. Points snap to 20px grid intersections. Press S to toggle point-to-point snap.

📐

Measurements

Segment lengths shown on canvas. Select a closed shape to see Area and Perimeter in the info panel below selection bar.

🖊

Shape Recognition

Draw freehand → select it → click Recognize in selection bar. System converts rough drawing to clean geometric shape.

💾

Export

File → Export PNG to download canvas as image. File → Save downloads JSON. Data auto-saves to browser storage.
